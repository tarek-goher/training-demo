# FBI Training — Demo (نسخة تجريبية)

نسخة تجريبية من نظام إدارة الجروبات والتدريب، بتشتغل **بالكامل جوه المتصفح** (من غير سيرفر). تتنشر على GitHub Pages وتتبعت كلينك للعميل يجرّب.

**اللي العميل يقدر يعمله:** يضيف كورسات بأسعارها ودكاترتها، يعمل جروبات (أسابيع × أيام)، يضيف طلاب ويسجّل الدفع على دفعات، يعلّم الحضور والغياب، يشوف التقارير، يطبع الشهادات، ويغيّر اللوجو.

## ملاحظات مهمة
- **البيانات بتتحفظ في متصفح كل زائر** (localStorage) ومش بتتبعت لأي مكان. كل عميل بيلعب في نسخته الخاصة، ومحدش بيشوف بيانات التاني.
- لو العميل مسح بيانات المتصفح أو فتح اللينك من جهاز تاني، هيلاقي البيانات التجريبية الأصلية. فيه زرار **"إعادة ضبط البيانات"** فوق في الصفحة.
- الأسماء والأسعار والدكاترة بيانات **تجريبية** (في `src/api/seed.js` لو عايز تغيّرها).
- **الشهادات:** بتفتح صفحة فيها شهادة لكل طالب، والعميل يدوس *Print / Save as PDF* ويختار "Save as PDF". (النسخة الأصلية بتنزّل ملف ZIP فيه PDF لكل طالب، لكن ده محتاج سيرفر.)
- الصور واللوجو بتتصغّر وتتخزّن في المتصفح، فالأفضل صور صغيرة.

## النشر على GitHub Pages (مرة واحدة)
1. اعمل Repository جديد على GitHub (مثلًا `fbi-training-demo`).
   > GitHub Pages بيشتغل مع الـ repository **العام (Public)** في الحسابات المجانية.
2. من الفولدر ده:
   ```
   git init
   git add .
   git commit -m "FBI Training demo"
   git branch -M main
   git remote add origin https://github.com/<اسمك>/fbi-training-demo.git
   git push -u origin main
   ```
3. على GitHub: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**.
4. استنى دقيقة أو اتنين لحد ما يخلّص الـ Action (تاب **Actions**). اللينك هيبقى:
   `https://<اسمك>.github.io/fbi-training-demo/`

أي تعديل بتعمله وتعمله `git push` بينشر نفسه تلقائي.

## تشغيل محلي
```
npm install
npm run dev
```
